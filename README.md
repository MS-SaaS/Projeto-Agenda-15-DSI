**Explicação do funcionamento do projeto:** Esse projeto funciona com base de 5 diferentes arquivos ".html" que possuem conexões entre si, funcionando como diferentes páginas que contribuem para co-existência uma da outra. O "configs.css" é um estilizador universal para todas as páginas, onde criei as variáveis de estilo para qualquer modificador que eu pudesse usar nas páginas, assim, facilitando minha vida ao criar esse código por evitar que ele chegasse às milhares de linhas.

**Descrição do recurso novo adicionado:** Alguns, honestamente. Fiz um sistema de hover simples, primeira vez que faço isso, achei bem simples e parece algo que adiciona bastante ao visual do site. Além disso, acho que os dois recursos novos que adicionei mais notáveis foram o uso de diversos arquivos ".html" e a nova forma de configuração do "configs.css".

**Explicação de como esse recurso foi implementado:** O hover é bem simples, apenas precisei usar o "transform: translateY(-5px);" para fazer esse efeito. Quanto aos outros dois, usei hiperligações com o "< a>" para conectar os diferentes arquivos, com o objetivo de evitar fazer um só arquivo de "index.html" que fosse ter 3000 linhas. Quanto a reforma do "configs.css", apenas adaptei o estilo do site para que qualquer um dos 5 pudesse usufruir de um modelo "universal" do mesmo código de estilo.
